# Frontend Development Standards

## Code Quality

- Write clean, maintainable, scalable code
- Prefer composition over inheritance
- Use reusable component patterns
- Follow strict TypeScript practices
- Avoid unnecessary abstractions
- Keep components small and focused
- Ensure proper folder structure and naming conventions

## UI/UX Standards

- Prioritize user experience over visual complexity
- Maintain strong visual hierarchy
- Ensure consistency in spacing, typography, and colors
- Design mobile-first responsive layouts
- Focus on accessibility and usability
- Use smooth and meaningful interactions
- Minimize cognitive load for users

## Performance Standards

- Optimize rendering and bundle size
- Avoid unnecessary re-renders
- Use server/client components appropriately
- Lazy load heavy components when necessary
- Optimize images, fonts, and animations
- Maintain excellent Core Web Vitals

## Design System Principles

- Build reusable UI primitives
- Maintain consistent spacing and typography scales
- Use token-based styling architecture
- Prefer scalable component APIs
- Ensure components are accessible and extensible

# Next.js Project Rules

This project uses a newer version of Next.js that may differ from standard conventions.

## Mandatory Requirement

Before implementing or modifying features:

- Read the relevant documentation inside:
  `node_modules/next/dist/docs/`
- Verify APIs and conventions before coding
- Check for deprecated or experimental features
- Do not assume legacy Next.js behavior

## App Architecture

- Prefer App Router patterns
- Use Server Components by default
- Use Client Components only when necessary
- Follow modern data fetching strategies
- Keep business logic separated from UI logic

## Styling

Preferred stack:

- Tailwind CSS
- CSS Modules when appropriate
- Design-token-based styling
- Consistent spacing system
- Avoid inline styles unless necessary

## UX Expectations

Every interface should aim for:

- Clarity
- Accessibility
- Speed
- Responsiveness
- Scalability
- Production-grade polish
